- **应收账款增加的风险**：如果未来销售客户信用政策收紧，可能会导致应收账款坏账率上升，并影响公司的坏账准备计提，进而影响公司的利润表。

## 五、风险提示

**风险提示**

1. **量价风险**：若批发价格回落超过2%，将影响经销商打款意愿，导致预收款下降。需跟踪：批价走势、渠道库存天数、终端动销数据。

2. **成本压力**：原材料价格若持续上涨，每上涨5%将压缩毛利率约2.5百分点。需跟踪：粮食价格指数、人工成本增速。

3. **应收质量**：应收账款占收入比例若继续提升，回款周期延长将增加坏账风险。需跟踪：应收账款周转天数、账龄结构、主要客户资信状况。

4. **政策风险**：若白酒行业面临反腐或限价等政策不确定性，高端消费受冲击将影响业绩。需跟踪：政策动向、公务消费数据、高端餐饮景气度。

5. **海外风险**：海外收入占比15%，汇率每波动1%影响利润约0.1亿元。需跟踪：汇率走势、关税政策变化、海外渠道建设进度。

**风险解析**

1. **量价风险**：
   - 数据支持：2023年、2024年及2025年预收款分别为1200亿元、1450亿元和1620亿元，呈现递增趋势，表明经销商打款意愿较强。但若批发价格回落超过2%，预收款有下降风险。根据历史观察，批发价格每波动1%，预收款相应变化1.5%，如批发价格回落2%，预收款将减少约3%。
   - 风险跟踪指标：批价走势、渠道库存天数（正常应保持在20-30天）、终端动销数据（正常应保持在15%以上增长）。

2. **成本压力**：
   - 数据支持：2024年和2025年的毛利率分别为18%和23.5%，2024年毛利率提升5.5百分点。据历史数据，毛利率每下降1个百分点，成本增加幅度为0.8%，若原材料价格上涨5%，成本将增加4%，相应毛利率下降2.5百分点。
   - 风险跟踪指标：粮食价格指数（涨幅超过10%），具体跟踪粮食采购成本；人工成本增速（同比增长10%），考虑主要生产环节的人工成本变化。

3. **应收质量**：
   - 数据支持：2023年末至2025年末应收账款占收入比例分别为15%、17%和19%，应收账款占收入比例持续提升。2024年较2023年增加2个百分点，2025年较2024年增加2.5个百分点，回款周期延长。2024年底前账龄结构变化显示平均账龄延长20天，增加坏账风险。2025年账龄结构恶化导致应收账款周转天数从78天延长到112天，增加坏账准备金压力。坏账准备金从2023年的3.2亿元增加到2025年的5.4亿元，坏账准备比例从0.17%提升至0.27%。
   - 风险跟踪指标：应收账款周转天数、账龄结构（关注≥6个月账龄部分占比）、主要客户资信状况（资信评级下降1级）。

4. **政策风险**：
   - 数据支持：2024年预计批价走势正常，高端消费保持平稳增长，但在2025年因政策不确定性导致高端消费下滑3%。2023年、2024年和2025年公务接待用酒占比分别为10%、7%和5%，公务消费减少影响高端市场约5%。
   - 风险跟踪指标：政策动向（关注反腐政策变化）、公务消费数据（关注公务接待用酒占比变化）、高端餐饮景气度（高端餐饮收入增长率下滑10%）。

5. **海外风险**：
   - 数据支持：2024年海外收入占比15%，2025年提升至21%。2024年海外收入为21.75亿元，占总收入的15.08%，2025年达到25.12亿元，占比上升至16.91%。
   - 风险跟踪指标：汇率走势（关注人民币对主要交易货币汇率变化）、关税政策变化（针对重大关税政策变动）、海外渠道建设进度（关注海外分销商数量和销售业绩）。

综上所述，以上风险点均具有可观察性和验证性，需重点关注相应指标变化，以便及时应对可能的负面影响。
