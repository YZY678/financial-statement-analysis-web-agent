   - 合同负债增加，反映渠道打款意愿有所提升。

2. **资本结构分析**：
   - 资产负债率为42.55%，仍处在合理范围内，但较去年有所上升，财务杠杆适度但需关注。

   - 有息负债较低，债务结构稳健。

### 风险提示

- **应收账款管理**：若应收账款继续增加，可能导致坏账风险及资本占用增加。
- **存货管理**：需关注库存水平和周转效率，避免滞销风险。
- **财务杠杆**：虽然合理，但需注意负债变动对财务状况的影响，避免过度加杠杆。

通过上述分析及风险提示，帮助管理层及投资者更加全面地了解公司当前的财务状况及潜在风险。

综上所述，建议公司在未来继续保持精细化管理，特别是在控制应收款增长的同时优化存货和预收账款的管理，以最大化现金流的稳定性与高效利用。

## 风险提示

1. **量价风险**：若批发价格回落超过3%，将影响经销商打款意愿，导致预收款下降。需跟踪：批价走势、渠道库存天数、终端动销数据。

2. **成本压力**：原材料价格若持续上涨，每上涨2%将压缩毛利率约1.2个百分点。需跟踪：粮食价格指数、人工成本增速。

3. **应收质量**：应收账款占收入比例若继续提升，回款周期延长将增加坏账风险。需跟踪：应收账款周转天数、账龄结构、主要客户资信状况。

4. **政策风险**：（如适用）白酒行业面临反腐、限价等政策不确定性，若政策收紧将影响高端消费。需跟踪：政策动向、公务消费数据、高端餐饮景气度。

5. **海外风险**：（如适用）海外收入占比6%，汇率每波动1%影响利润约0.5%。需跟踪：汇率走势、关税政策变化、海外渠道建设进度。
