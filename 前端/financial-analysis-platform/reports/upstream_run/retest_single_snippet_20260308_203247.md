   - **收入增长显著**：2025年收入同比增长38.57%，主要得益于销量的激增32.86%和高端酒的价格提升8.23%。结构上，高端酒的占比提高2.62个百分点，表明公司成功提升了产品组合的价值。

2. **毛利率**：
   - **毛利率下滑**：2025年毛利率下降1.2个百分点至49%，原因在于成本增长速度远高于收入增长速度。成本中，原材料成本上涨10.2%，人工成本上涨3.5%。

3. **期间费用**：
   - **销售费用控制**：销售费用率从2024年的6.5%降至2025年的5.9%，下降了0.6个百分点，表明公司在销售推广上的效率有所提升。
   - **管理费用下降**：尽管管理费用率仍较高，但2025年下降1.1个百分点，显示公司在行政管理效率方面有改进。
   - **研发费用增加**：2025年研发投入同比增长0.5个百分点，表明公司仍注重长远研发。

4. **净利润**：
   - **净利润稳步增长**：尽管毛利率有所下降，但2025年归母净利润仍同比增长34.35%至268000万元。净利率从2024年的16.07%上升至2025年的17.15%，提升了1.08个百分点，显示出公司整体盈利能力的增强。
   - **ROE保持良好水平**：2025年度ROE为26.55%，维持在一个较高水平，表明企业资产使用效率良好。

**风险提示**：
如果未来原材料价格持续上涨，可能进一步压缩毛利率，进而影响净利润水平。同时，如果高端酒需求不及预期或者市场竞争加剧，也将对高毛利率产品的销售产生不利影响。
