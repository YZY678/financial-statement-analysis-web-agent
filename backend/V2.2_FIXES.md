# V2.2 稳定性修复说明

## 修复的3个问题

### 问题1：指标提取范围太小 🟡

**原问题**：
```python
# llm_client.py - extract_metrics()
tables_json[:12000]  # 只取前12000字符
```

❌ **影响**：
- 年报/季报表格很容易被截断
- 后面的关键指标（净利润、现金流等）提取不到
- 导致大量 N/A

**修复方案**：
```python
# 扩大到30000字符
tables_subset = tables_json[:30000] if len(tables_json) > 30000 else tables_json

# 增加提示
system = """
7. 【关键】如果某个指标在前面的表格中找不到，继续往后找，不要轻易放弃
"""

# 增加容错
try:
    data = json.loads(content)
except json.JSONDecodeError as e:
    print(f"⚠️ JSON修复失败: {e}")
    # 返回空数据结构，避免程序崩溃
    data = {
        "period": "未知期间",
        "scope": "unknown",
        "unit_standard": "亿元",
        "items": {}
    }
```

**修复效果**：
- ✅ 提取范围扩大2.5倍
- ✅ 减少指标缺失
- ✅ 增加容错处理

### 问题2：matplotlib硬依赖导致崩溃 🟡

**原问题**：
```python
# code_runner.py
import matplotlib  # 硬依赖，装不上就崩溃
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import numpy as np
```

❌ **影响**：
- 如果matplotlib装不上，程序直接崩溃
- 无法生成报告（即使不需要图表）

**修复方案**：
```python
# matplotlib改为可选依赖
try:
    import matplotlib
    matplotlib.use('Agg')
    import matplotlib.pyplot as plt
    import numpy as np
    MATPLOTLIB_AVAILABLE = True
except ImportError:
    MATPLOTLIB_AVAILABLE = False
    print("⚠️ matplotlib未安装，图表生成功能将被禁用")

def plot_charts(...):
    # 如果matplotlib不可用，返回占位符
    if not MATPLOTLIB_AVAILABLE:
        print("⚠️ matplotlib不可用，跳过图表生成")
        placeholder_path = out / "chart_placeholder.txt"
        placeholder_path.write_text(
            "图表生成功能需要安装matplotlib\n"
            "请运行: pip install matplotlib numpy\n"
            "然后重新生成报告",
            encoding="utf-8"
        )
        return "output/charts/chart_placeholder.txt"
    
    # 正常生成图表...
```

**修复效果**：
- ✅ matplotlib变为可选依赖
- ✅ 装不上也能生成报告（只是没图表）
- ✅ 提供友好的提示信息

### 问题3：Windows反斜杠路径不兼容 🟢

**原问题**：
```python
# code_runner.py
return str(save_path)  # 返回绝对路径
# 输出：H:\backend\output\charts\financial_chart.png
```

❌ **影响**：
- Markdown渲染器不认Windows反斜杠 `\`
- 绝对路径在其他电脑上无效
- 导致"有图也显示不出来"

**修复方案**：
```python
# 使用相对路径 + 正斜杠
return "output/charts/financial_chart.png"

# 所有返回路径都改为相对路径
if not MATPLOTLIB_AVAILABLE:
    return "output/charts/chart_placeholder.txt"

if history.get("dates"):
    # ...生成图表
    return "output/charts/financial_chart.png"

if not has_data:
    # ...生成占位图
    return "output/charts/financial_chart.png"
```

**修复效果**：
- ✅ 使用相对路径（兼容所有系统）
- ✅ 使用正斜杠（兼容所有Markdown渲染器）
- ✅ 图片可以正常显示

```bash
# 
# 内容：
# 图表生成功能需要安装matplotlib
# 请运行: pip install matplotlib numpy
# 然后重新生成报告
```

### 2. 如果指标提取不全

```bash
# 查看调试输出
python main.py report.pdf

# 输出：
# === 原始抽取结果 ===
# {'revenue': 170.61, 'net_income': None, ...}
#
# === 数据校验警告 ===
# ⚠️ 净利润为空，请检查表格是否完整
```

**解决方案**：
- 检查PDF是否完整
- 检查表格是否被正确解析
- 尝试增加 `tables_subset` 范围

### 3. 如果图片显示不出来

**检查**：
- 图片路径是否为相对路径
- 是否使用正斜杠 `/`
- Markdown渲染器是否支持

**正确格式**：
```markdown
![财务指标可视化](output/charts/financial_chart.png)
```

**错误格式**：
```markdown
![财务指标可视化](H:\backend\output\charts\financial_chart.png)  ❌
![财务指标可视化](H:/backend/output/charts/financial_chart.png)  ❌
```
