### 分析

【利润表分析】

#### 一、营业收入

- **分产品**：

#### 二、毛利率
- **综合毛利率**：92.01%，同比-0.19 ppt
  - **原因**：成本增速16.20% vs 收入增速15.71%。其中，原材料成本+19.81%，人工成本+16.31%

#### 三、期间费用

- **管理费用率**：5.48%，同比-0.43 ppt
- **研发费用率**：0.13%，同比+0.02 ppt

#### 四、净利润
- **归母净利润**：86,228,146,421.62元，同比+15.38%
- **净利率**：50.52%，同比-0.91 ppt
- **ROE**：36.02%，同比增加1.83个百分点

#### 风险提示
- 如果原材料成本持续上升，会对综合毛利率产生较大压力，可能影响利润率水平。
- 如果市场推广及服务费进一步增加，会相应增厚销售费用，影响整体费用率。

【结论及建议】
1. **收入增长稳健**：2024年收入同比增长15.71%，反映出市场需求稳定增长。
2. **毛利率有所下降**：主要由于成本上升，尤其是原材料和人工成本上升，导致毛利率略有下降。
3. **期间费用管控良好**：销售费用增长主要因市场推广投入增加，管理费用率下降，研发费用率变化不大。
4. **净利润继续保持高位**：归母净利润和净利率保持较高水平，显示公司盈利能力较强。

- **应收账款增长**：应收账款占收入增加至4.49%，可能导致公司资金回收压力增大。建议加强信用管理，缩短应收账款周转天数。

- **货币资金充足**：公司拥有大量现金，但也需关注现金使用效率，避免资金闲置导致的机会成本。

- **外部依赖风险**：预收款项增加反映了渠道和市场需求的变化，但也应警惕销售政策或市场环境的变化导致的风险。

### 结论

综合来看，公司在2024年度保持了良好的财务结构和稳健的营运资本管理，但仍然需要注意应收账款和存货管理，确保资金使用效率和降低潜在风险。

## 五、风险提示

【风险提示】

1. **量价风险**：如果批发价格回落超过1.2%，将抑制经销商打款意愿，导致预收款下降。需跟踪：批发价格走势、渠道库存天数、终端动销数据。

2. **成本压力**：如果原材料价格每上涨2%，将压缩毛利率约1.2个百分点。需跟踪：粮食价格指数、人工成本增速。

3. **应收质量**：如果应收账款占收入比例继续提升，回款周期延长将增加坏账风险。需跟踪：应收账款周转天数、账龄结构、主要客户资信状况。

4. **政策风险**：若行业面临反腐、限价等政策不确定性，尤其在高端消费层面收紧，将影响公司收入。需跟踪：政策动向、公务消费数据、高端餐饮景气度。

5. **海外风险**：由于海外收入占比6.7%，汇率每波动1%，将影响利润约3%。需跟踪：汇率走势、关税政策变化、海外渠道建设进度。
